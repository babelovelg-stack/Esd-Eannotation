# Esd-Eannotation Figma Community 发布包

本目录包含 Esd-Eannotation 的 Figma Community 发布材料。公开名称、分类、价格、标语和中英文说明以 `../../../docs/publish-copy-approved.md` 中的 Esd-Eannotation 段落为权威来源；中文为主，英文为补充。

## 文件索引

- `listing-copy.md`：发布页名称、标语、分类、价格和说明。
- `privacy-policy.md`：与当前实现一致的隐私说明。
- `data-security.md`：数据安全披露和发布表单建议答案。
- `support-template.md`：FAQ 与问题反馈模板；不预设联系信息。
- `release-notes.md`：首发版本说明。
- `review-checklist.md`：技术、视觉、审核检查清单。
- `playground-file-plan.md`：可选 Playground 文件搭建说明。
- `assets/icon-128.png`：Community icon，128 × 128px。
- `assets/thumbnail-1920x1080.png`：Community thumbnail，1920 × 1080px。
- `assets/carousel-01-core.png`、`carousel-02-workflow.png`、`carousel-03-boundaries.png`：轮播图，均为 1920 × 1080px。

## 发布前确认

- Figma 桌面端发布、双因素认证和发布表单要求以 Figma 当前流程为准。
- `manifest.json` 的插件 ID 必须保持为 `1643518934362352424`，并声明无网络访问。
- 在发布表单中填写真实可用的支持方式；如需要独立隐私政策 URL，请先确定实际托管地址。本仓库不提供虚构 URL 或联系方式。
- 提交前按 `review-checklist.md` 验收并确认 `privacy-policy.md`、`data-security.md` 与实际实现一致。
