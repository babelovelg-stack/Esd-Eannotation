# Esd-Eannotation Playground 文件搭建说明

Playground file 为可选项，可帮助用户在安装前了解 Esd-Eannotation 的单选工作流。

## 推荐页面结构

### Page 1：试用 Esd-Eannotation

- 顶层 Frame：`Global annotation example`
- 嵌套 card 或 button：`Local annotation example`
- 绑定文字样式或变量的文本节点
- 使用填充变量的矩形
- 带 auto layout、padding、gap、border、radius 的组件

### Page 2：生成结果

- 全局交付卡片
- 局部编号 badge 与卡片
- 图文、图片和属性标注示例
- 变量/样式优先与盒模型示例

## 文件内说明

```text
1. Select one layer in this file.
2. Run Esd-Eannotation.
3. Add a note, paste an image, or choose property annotations.
4. Click Create annotation.
```

发布时保持 Playground 简洁，不包含敏感业务稿或真实产品数据，并确保示例变量、样式和组件可公开分享。
