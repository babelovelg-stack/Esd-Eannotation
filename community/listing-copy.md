# Esd-Eannotation 社区发布页文案

## 名称

Esd-Eannotation

## 标语

在画布上生成结构化设计交付卡片

English: Create structured design handoff cards on the canvas.

## 分类与价格

- 分类：Design tools
- 价格：免费

## 中文说明

Esd-Eannotation 帮助设计师直接在 Figma 画布上生成清晰、结构化的设计交付卡片。

选择一个图层后，你可以输入说明、添加图片并勾选需要展示的属性。插件会根据图层层级自动创建全局交付卡片，或为 Frame 内的元素创建带编号的局部卡片。

核心能力：

- 自动识别全局与局部交付场景
- 为局部卡片生成对应的编号标记
- 支持文字说明、本地图片上传和剪贴板图片
- 支持宽高、最小/最大尺寸、填充、描边、文字样式、文字颜色、圆角和盒模型
- 优先展示绑定变量，其次展示样式，最后才展示原始值
- 为同一元素继续追加内容，避免重复创建编号
- 无网络访问

Esd-Eannotation 当前仅支持单选。它生成的是保留在画布中的可见 Figma 节点，不会创建或替代 Figma 原生 Annotations，也不会把设计内容发送到外部服务。

## English supplementary description

Esd-Eannotation creates visible, structured handoff cards as Figma canvas nodes. Add text, images, and selected property specs, with automatic global or numbered local placement. It does not replace native Figma Annotations and has no network access.
